# 🎬 Sweep Logic App Demo Guide

## 🚀 Quick Start Demo

### **1. Launch the App**
```bash
npm start
```
- Scan QR code with Expo Go app
- Or press 'w' to open in web browser

### **2. Test Role Switching**
1. **Home Screen** → Tap the role switcher (top-right)
2. **Customer Mode**: See job posting, offers, payments
3. **Cleaner Mode**: See job browsing, earnings, schedule
4. **Switch Back**: Experience different interfaces

### **3. Test Each Screen**

#### **🏠 Home Screen Features**
- ✅ **Role-based Dashboard**: Different content for each role
- ✅ **Quick Actions**: Tap buttons with badges
- ✅ **Analytics Cards**: View statistics and trends
- ✅ **Recent Activity**: See job history
- ✅ **Pro Tips**: Contextual advice

#### **💼 Jobs Screen Features**
- ✅ **Search Bar**: Type "apartment" or "downtown"
- ✅ **Filter Buttons**: Tap "Urgent" or "Regular"
- ✅ **Job Cards**: View detailed job information
- ✅ **Property Details**: Bedrooms, bathrooms, type
- ✅ **Budget Ranges**: Min-max pricing
- ✅ **Submit Offer**: Cleaner action button

#### **💬 Messages Screen Features**
- ✅ **Chat List**: View all conversations
- ✅ **Search**: Find specific chats
- ✅ **Filter Options**: All, Active, Unread
- ✅ **Unread Badges**: See message counts
- ✅ **Online Indicators**: Green dots for active users

#### **👤 Profile Screen Features**
- ✅ **User Profile**: Avatar and stats
- ✅ **Settings Toggles**: Try notification settings
- ✅ **Account Menu**: Tap different options
- ✅ **Role-based Stats**: Different metrics per role
- ✅ **Sign Out**: Red logout button

### **4. Test Responsive Design**
- **Rotate Device**: Test landscape/portrait
- **Different Sizes**: Try on phone vs tablet
- **Dark/Light Mode**: Switch system theme

### **5. Test Interactive Elements**
- ✅ **Touch Feedback**: All buttons respond
- ✅ **Smooth Scrolling**: Test all scrollable areas
- ✅ **Search Functionality**: Type in search bars
- ✅ **Filter Toggles**: Switch between options
- ✅ **Settings Switches**: Toggle on/off
